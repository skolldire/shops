What should the file do with the stock?

The units in the file are added to the units in stock, for example to record a delivery. Prices, names and the other fields are replaced by the file.

The units in the file become the units in stock, for example after a stock count. A product cannot go below the units reserved by pending purchases.

UTF-8. The first line must be name,sku,description,category,price,stock,weight_kg. Nothing changes until you confirm the preview on the next page.
